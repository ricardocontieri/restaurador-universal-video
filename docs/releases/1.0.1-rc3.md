# Universal Video Restorer 1.0.1-RC3

Status: **release candidate**. This build is not yet the stable 1.0.1 release.

## Why RC3 exists

RC3 is calibrated from a blind side-by-side evaluation of the adaptive RC2 line against RC3 Preview2. The goal is not to increase stabilization globally, but to preserve Preview2 gains while reverting or constraining scene classes where the blind test exposed regressions.

## Main changes

### More selective photometric guard

Weak photometric events no longer automatically promote a scene into protected tracking. RC3 raises the evidence threshold and preserves the base adaptive profile when the transition signal is weak.

### Detector-only photometric assistance

For high-shake, low-pan scenes with reliable motion agreement, RC3 can keep the base transformation parameters while using preprocessing only for `vidstabdetect`. The final master is never brightened or denoised by this tracking helper.

### Spatial tracking consensus

Scenes with strong local motion or transient occlusion can be probed using FULL, TOP70, BOTTOM70, LEFT70, RIGHT70 and CENTER80 detector views. The selected region is based on agreement with the other trajectories plus tracking quality. The crop is detector-only; the master remains full frame.

### Selective dynamic-motion override

The normal override threshold is higher than Preview2, reducing unnecessary intervention in scenes where the base adaptive profile was already visually stronger.

### Transition reacquisition

Difficult low-light pans and strong photometric transitions may trigger a conservative reacquisition attempt. A candidate detector path is accepted only when tracking quality improves while retaining minimum agreement with the prior trajectory.

### Voice-safe audio

The denoise stage is deliberately less aggressive after blind evaluation showed that stronger noise reduction could alter narration timbre. RC3 uses conservative `afftdn` settings and only applies the high-pass path when wind evidence is strong. Two-pass loudness normalization and the ultrashort/silent fallback remain unchanged.

## Preserved guarantees

- exact decoded-frame census;
- no `-shortest` in the final mux;
- conservative pillarbox deep validation;
- detector preprocessing never changes master pixels;
- SHA-256 provenance and historical-timestamp policy;
- CUDA/QSV per-file benchmarking with CPU fallback;
- checkpoint/resume behavior;
- Unicode-safe concat handling;
- strict final frame-count and smoke-decode validation.

## Validation status

Static validation completed for the RC3 artifact included function uniqueness, delimiter balance, prohibited-argument checks and isolated FFmpeg-chain execution. Runtime promotion is intentionally gated by a 14-case blind A/B comparison against the best previously observed result for each calibration clip.

The first full execution under PowerShell 7.6.5 remains the authoritative syntax/runtime validation. Stable `1.0.1` should only be published after the blind calibration gate is passed.

## Version identity

The RC3 publication also corrects stale Preview2 wording in the console banner and adaptive-audio status text; this correction is cosmetic and does not change processing behavior.
